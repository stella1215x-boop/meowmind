## 🚀 Core Features

### 📝 3-Line Daily Journal
Simple, low-friction journaling designed for consistency.
Users write just 3 lines per day — reducing mental barrier to entry.

### 🐱 Virtual Cat Companion (Rive Animation)
- Cat reacts to journaling activity with real-time emotions
- Cat grows as users maintain streaks
- Built with **Rive** for smooth, interactive animations

### 🎮 Gamification & Retention Loop
- Daily check-in rewards
- Streak-based progression system
- Coin rewards for consistent journaling
- Intimacy tier system — deeper bond = more cat interactions

### 🛍️ In-App Economy
- Coin purchase system for extended interactions
- Food & item shop for cat customization
- Designed to drive voluntary re-engagement (not forced monetization)

## 💡 Key Product Decisions

**Why a cat?**
Pets create emotional attachment. Attachment drives retention. Retention drives habit formation — which is the core goal of a mental wellness app.

**Why 3 lines only?**
Friction is the #1 reason journaling habits fail. Reducing the commitment to 3 lines lowers the barrier while maintaining consistency.

**Why gamification?**
Intrinsic motivation alone doesn't sustain long-term behavior change. External reward loops (coins, cat growth, streaks) bridge the gap until journaling becomes intrinsic.
